## Project Overview

Interactive dashboard built with Streamlit and Plotly to visualize e-commerce sales data .

**Goal:** Transform static analysis into an interactive web application.

---

## Features 

- KPI cards (Total Sales, Customers, Orders)
- Interactive charts (Top Products, Monthly Trend, Geographic)
- Filters (Country, Month, Product Category)
- Real-time data updates

---

## Tech Stack

- **Python**
- **Streamlit** — Dashboard framework
- **Plotly** — Interactive charts
- **Pandas** — Data manipulation

## How to Run

1. Install requirements: pip install -r requirements.txt

2. Run the dashboard: streamlit run app.py
